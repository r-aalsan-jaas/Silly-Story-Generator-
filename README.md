# 🧙‍♂️ Silly Story Generator

This is a fun and interactive web project that generates random silly stories every time you click a button! You can personalize it by entering your own name and choosing your region (US or UK) to see different units like temperature and weight.

## Features

- Generates random and humorous stories
- Custom name input
- Supports both US and UK unit formats
- Lightweight and beginner-friendly code

## 🛠️ Tech Used

- HTML
- CSS
- JavaScript
